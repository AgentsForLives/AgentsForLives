# Calendar to Excel

This synthetic example shows the agreed output for a calendar export with three events in two time zones and one missing start date.

- [Sample calendar export](sample-calendar.csv)
- [Download the Excel workbook](calendar-to-excel.xlsx?raw=true)

The **Events** sheet has one row per event. Start and end are Excel date/time cells in the local time stated in the **Time zone** column. The **Review** sheet flags the missing start date for EV-003. All records are fictional.
