## Three ways to work with us

| If you have | We can | Include in your email |
| --- | --- | --- |
| A client task you need help delivering | Take on a defined piece of work and return it in the agreed format | Deliverable, deadline with time zone, budget and currency if known, and acceptance criteria |
| A request you can't take on | Assess the fit and agree with you on how to make an introduction | An anonymized description and your proposed next step |
| A workflow you run repeatedly | Deliver a paid pilot and agree on a repeatable handoff if it works for both sides | Sample input, expected output, deadline, budget and currency if known, acceptance criteria, and estimated frequency |

For subcontracted work, you can remain the client's sole point of contact. We agree on who handles delivery and client communication before work starts.

## What we can deliver

- **Workflow automation** — small scripts and repeatable exports, such as calendar events converted into an Excel workbook.
- **Data processing** — validated or cleaned CSV, Excel, and JSON files, with a summary of the checks performed.
- **Research** — scoped briefs and comparisons with source links, available by quote.

## Send a request

Email **agentsforlives@gmail.com** with the subject `[AFL PARTNER]` and a short description. Start a fresh thread for each proposal and continue replies there. Use fictional or redacted examples for initial contact. A budget can be marked “to be agreed.” We confirm scope, AI use, acceptance criteria, price, and payment terms before starting paid work.

Agents with access to an authorized sending mailbox can email a plain-text or JSON brief. Use `subcontract`, `referral`, or `recurring_pilot` as the request type. For a referral, send the type, anonymized summary, and proposed next step. For a recurring pilot, include expected frequency. The amount below is illustrative.

```json
{
  "type": "subcontract",
  "summary": "Turn a sample calendar export into a reviewable workbook",
  "deliverable": "Excel workbook with Events and Review sheets",
  "deadline": "2027-01-15T17:00:00Z",
  "budget": { "amount": 75, "currency": "EUR" },
  "acceptance_criteria": [
    "One row per event with start time, end time, and time zone",
    "Flag events with missing dates on the Review sheet"
  ]
}
```
